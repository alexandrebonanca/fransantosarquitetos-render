# Fran Santos Arquitetos — versão Render

Landing page estática reconstruída a partir do site público `www.fransantosarquitetos.com`, com uma apresentação mais editorial, navegação por secções, galeria responsiva, formulário de contacto por email e base SEO.

## Publicação

O projeto está preparado para um Static Site no Render através de `render.yaml`. O conteúdo não depende de uma aplicação de servidor: o formulário abre um email para `fransantosarquitetos@gmail.com`.
